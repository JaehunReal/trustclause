# TrustClause™ — 위·수탁 계약 자동 생성 & 컴플라이언스 웹 플랫폼

개인정보 처리 위·수탁 계약(「개인정보 보호법」 제26조)과 공공·지자체 행정사무 민간위탁 협약(「지방자치법」 제117조, 행안부 민간위탁 관리지침)을 자동으로 생성하고, 현행 계약 관행의 단점을 실시간으로 검증·보완하는 정적 웹 애플리케이션입니다.

## 주요 기능
- 🧭 계약 유형 적격성 진단 마법사 (처리위탁 vs 제3자 제공 / 민간위탁 협약 vs 일반 용역)
- ✅ 실시간 법령 컴플라이언스 린터 (10개 항목, 100점 만점) + 원클릭 자동 보완
- 📋 재위탁(Sub-processor) 매트릭스 → [별표 1] 자동 연동
- 🔒 취급 정보 위험도에 따른 안전성 확보조치 자동 매핑
- 📎 부속서류 4종 자동 생성 (보안서약서, 파기확인서, 실태점검표, 근로조건 보호 확약서)
- 📅 사후관리 D-Day 타임라인 + 논문·실태조사 허브
- 🖨️ 인쇄/PDF, Word/한글(.doc), PDR(.md) 내보내기

## 실행
빌드 과정 없이 `index.html`을 브라우저로 열면 됩니다.
